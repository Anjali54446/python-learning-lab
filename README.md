## Learning Outcomes

By the end of the training, learners should be able to:

-   Explain basic Python concepts and write simple programs.
-   Store information in variables and use common data types.
-   Accept user input, display output, and perform calculations.
-   Use `if`, `elif`, and `else` to make decisions.
-   Work with strings and Python collections.
-   Use loops to repeat tasks and control loop execution.
-   Create and call functions to organise reusable code.
-   Use list and dictionary comprehensions for concise transformations.
-   Handle common errors using `try`, `except`, and related constructs.
-   Read from and write to text files and work with basic CSV data.
-   Import standard-library modules and understand custom modules and
    packages.
-   Break a problem into smaller steps, test solutions, and debug
    errors.

## Session Details

### Session 1 --- Python Basics

**Topics** - Introduction to Python and the coding environment -
Variables and data types - Operators and expressions - Input and
output - Conditional statements

**Practice examples** - Data-type demonstrations - Number and operator
exercises - Taking input from the user - A simple calculator -
Conditional logic and a grade checker

**Folder:** `Session-1-Python-Basics/`

### Session 2 --- Strings and Collections

**Topics** - Strings and common string operations - Lists - Tuples -
Sets - Dictionaries - Nested collections and JSON examples

**Practice files** - `strings.py` - `lists.py` - `tuples.py` -
`sets.py` - `dictionaries.py` - `nested_data.py` - `json_example.py`

**Folder:** `Session-2-Strings-and-Collections/`

### Session 3 --- Practical Lab: Foundations and Collections

This session gives learners hands-on practice using concepts from the
first two sessions. The examples focus on translating a problem into
steps, writing code, checking results, and correcting mistakes.

**Practice areas** - Calculations and user input - Conditional logic -
Strings and collections - Combining multiple concepts in one program -
Debugging and reading error messages - Independent practice and homework

Example files use the naming pattern `problem_01_description.py`.

**Folder:** `Session-3-practicals/`

### Session 4 --- Loops, Functions and Python Essentials (Theory)

**Topics** - `for` loops and `while` loops - `range()`, nested loops,
and loop patterns - `break`, `continue`, and `pass` - Defining
functions, parameters, return values, and reusable logic - List and
dictionary comprehensions - Exception handling - Text-file and CSV
handling - Modules, packages, and installing packages with `pip` -
Connecting Python concepts in a small integrated example

Use this session to understand the concepts before working through the
Session 5 practical examples.

**Folder:** `Session-4-loops-functions/`

### Session 5 --- Practical Lab: Loops, Functions and Essentials

**Guided practice** - Printing number sequences - Finding even numbers
and calculating sums - Generating multiplication tables - Calculating
factorials - Checking prime numbers and finding primes in a range -
Writing functions for calculations and reusable checks - Building a
calculator with functions - Using list and dictionary comprehensions -
Handling division-by-zero and invalid input - Writing and reading text
files - Reading CSV data and handling missing files - Using
standard-library modules such as `math`, `random`, and `datetime` -
Counting words in a document

**Homework** - Pattern printing with nested loops - Counting vowels -
Writing functions for common tasks - Practising comprehensions - Input
validation and a menu-based calculator - Counting words and lines, and
appending to a file - Exploring custom modules and package installation

Example files use the naming patterns `problem_01_description.py` and
`homework_01_description.py`.

**Folder:** `Session-5-practicals/`

## How to Use This Repository

1.  Open the repository on GitHub.
2.  Choose the session you are learning.
3.  Open the relevant `.py` file and read the comments and code.
4.  Predict what the program will do before running it.
5.  Run the example and compare the output with your prediction.
6.  Change the input or values and observe what changes.
7.  Try the homework independently before looking at a solution.

### Run the examples in Google Colab

1.  Open [Google Colab](https://colab.research.google.com/).
2.  Create a new notebook.
3.  Copy the contents of a `.py` example into a code cell, or upload the
    Python file.
4.  Run the cell and inspect the output.
5.  For file-handling examples, make sure the required input file is
    available in the Colab session.

You can also run a Python file from a terminal if Python is installed:

``` bash
python filename.py
```

Replace `filename.py` with the name of the example you want to run.

## Tips for Beginners

-   Type out the examples yourself instead of only copying and pasting.
-   Pay attention to indentation; Python uses indentation to define code
    blocks.
-   Read error messages carefully and identify the line where the error
    occurs.
-   Test programs with normal, boundary, and unexpected inputs.
-   Use meaningful variable and function names.
-   Practise a little every day and revisit earlier exercises.
-   Do not worry about making mistakes---debugging is part of learning
    to program.
