## Run the code

### Google Colab
1. Open https://colab.research.google.com/
2. Upload the selected `.py` file through the Files panel.
3. Run it with `%run /content/filename.py`, replacing `filename.py` with the selected file.
4. Alternatively, paste the code into a notebook cell and run it.

### Local Python
Open a terminal in this folder and run `python filename.py`.

Some programs ask for input. Enter the requested values when prompted.

## Teaching tip
Ask learners to attempt each problem from the slides before showing the complete solution. Change the inputs or sample data to test the program.
