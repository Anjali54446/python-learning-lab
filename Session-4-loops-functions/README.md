# Session 4 — Loops, Functions & Essentials

Complete runnable Python examples aligned with the Day 4 theory slides.


## Run in Google Colab
1. Open https://colab.research.google.com/
2. Upload the `.py` file using the Files panel, or paste the code into a notebook cell.
3. Run an uploaded file with `%run /content/example_01_loop_basics.py`.
4. Change the filename for another example.

For the `!pip install requests` demonstration, use the dedicated Colab notebook/shell cell shown in `example_15_pip_requests_colab.py`; `!pip` syntax is specific to notebook cells, not ordinary `.py` scripts.

## Important
- The files are independent examples. Run one at a time.
- `while` examples include a stopping condition; do not remove it without a plan to stop the loop.
- Files created in Colab's temporary runtime may disappear when the runtime resets.
- Use only trusted third-party packages.
