1. Open https://colab.research.google.com/
2. Upload a `.py` file through the Files panel, or paste its code into a cell.
3. Run an uploaded file using `%run /content/problem_01_print_1_to_100.py`.

Programs using `input()` will prompt for values. Files created in Colab are stored in its temporary runtime unless downloaded. The `!pip install` instruction is for a Colab code cell, not an ordinary `.py` script.
