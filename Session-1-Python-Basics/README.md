# Session 1 — Python Basics

Welcome to **Session 1 of the Python Learning Lab**!

This folder contains beginner-friendly Python programs demonstrating the fundamentals of Python programming. These examples are designed for live demonstrations and hands-on practice using Python.

## 🎯 Learning Objectives

By the end of this session, learners will be able to:

- Understand variables and basic data types.
- Perform calculations using Python operators.
- Accept input from users and display output.
- Write simple calculator programs.
- Use conditional statements to make decisions.
- Check student marks and calculate grades.

## 📚 Topics and Examples

### 1. Data Types
**File:** `datatypes.py`

Learn about Python's basic data types:
- Integer (`int`)
- Float (`float`)
- String (`str`)
- Boolean (`bool`)

### 2. Operators
**Folder:** `Operators/`

Explore arithmetic and other basic operators to perform calculations and compare values.

### 3. Input and Output
**File:** `input.py`

Learn how to accept user input using `input()` and display results using `print()`.

### 4. Numbers
**File:** `numbers.py`

Practise working with comparing numbers.

### 5. Simple Calculator
**File:** `simple_calculator.py`

Build a basic calculator to demonstrate arithmetic operations in Python.

### 6. Conditional Statements
**Folder:** `Conditional_Statements/`

Learn how to control program flow using:
- `if`
- `if-else`
- `if-elif-else`

### 7. Grade Checker
**File:** `grade_checker.py`

Create a program that checks student marks and determines a grade based on specified conditions.

## ▶️ How to Run the Programs

### Option 1: Using Google Colab

1. Open [Google Colab](https://colab.research.google.com/).
2. Select **File → Upload notebook** if you have a notebook file.
3. For `.py` files, upload the file to Colab's file panel and run it using:

   ```python
   %run /content/numbers.py
   ```

   Replace `numbers.py` with the name of the file you want to run.

### Option 2: Using Python on Your Computer

1. Install Python if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the `Session-1-Python-Basics` folder.
4. Run a program using:

   ```bash
   python numbers.py
   ```

   Replace `numbers.py` with the desired filename.
