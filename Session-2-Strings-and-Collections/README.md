# Session 2 — Python Strings and Collections

Welcome to **Session 2 of the Python Learning Lab**!

This folder contains beginner-friendly examples for strings, lists, tuples, sets, dictionaries, nested data, and JSON.

## Learning Objectives
- Use string indexing, slicing, and methods.
- Create, access, update, and remove list items.
- Understand tuples and unpacking.
- Use sets to store unique values and compare groups.
- Store and retrieve data with dictionaries.
- Work with nested data and JSON.

## Examples

| File | Topics |
|---|---|
| `strings.py` | Indexing, slicing, string methods, f-strings |
| `lists.py` | Accessing, adding, updating, and removing items |
| `tuples.py` | Tuple access and unpacking |
| `sets.py` | Unique values, union, intersection, difference |
| `dictionaries.py` | Key-value pairs, updates, `.get()` |
| `nested_data.py` | Lists of dictionaries for student records |
| `json_example.py` | Python data to JSON and back |

## Run the examples

### Google Colab
1. Open [Google Colab](https://colab.research.google.com/).
2. Upload a `.py` file using the Files panel, or paste its code into a code cell.
3. Run an uploaded file with `%run /content/strings.py` (replace the filename as needed).

### On your computer
Open a terminal in this folder and run `python strings.py`. Replace the filename to run another example.

## Practice Challenges
1. Ask for a sentence and print it in uppercase and lowercase.
2. Create a list of favourite foods; add and remove an item.
3. Create a tuple for a book and unpack its values.
4. Convert a list with repeated numbers into a set.
5. Create a student dictionary and update the marks.
6. Create a list of dictionaries for three students.
7. Add a field to a dictionary and convert it to JSON.

## Requirements
- Python 3
- Google Colab or a local Python environment
- No additional packages are required (`json` is included with Python).
